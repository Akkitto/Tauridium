# Tauridium 1.0.8 release validation

Require all canonical formatting, strict lint, application tests, current
advisories, native production builds and clean exact-tag packaging gates.
Source/runtime/docs ZIPs must be integrity checked, repeat byte-identically
on the same producer and pass the pinned artifact scanner. Existing signing,
provenance, installer and public-inventory controls remain required.

Native Ubuntu x64 and ARM64 AppImage jobs must independently verify the bundled
GStreamer plugins, scanner, architecture and runtime search-path confinement,
then execute real WAV/Ogg/WebAudio playback through a production service WebView.
Require actual nonzero PCM output, intermediate silence and repeated playback
using an isolated profile/display/bus/private null sink. No real speaker,
personal account, host plugin fallback or WebKit sandbox disabling is permitted.
Official release producers repeat the audio gate on the actual bundled assets
before collection and signing. See [Linux audio](../LINUX-AUDIO.md).

Windows x64/ARM64 title-bar, application and clean-machine installation tests and
both Nix architecture consumers remain required. This document states the
requirements; current execution results are recorded outside the repository.
