# Tauridium 1.0.7 release validation

This release requires `just release` from a clean candidate and exact-tag packaging
through `just package`. Source/runtime/docs ZIPs must have valid CRCs, repeat
byte-identically on the same producer, and pass the pinned artifact scanner.

The native Windows production gate runs on fresh x64 and Windows 11 ARM64 CI
profiles. It requires native caption-button rectangles and hit targets, uncovered
window controls, real popup menus, bounded Advanced toggle geometry, verified
settings persistence, unified/classic/unified restarts with stable outside sizes,
and maximize/minimize/restore and keyboard menu navigation. Existing personal
profiles are excluded from this automated gate. See [the title-bar guide](../WINDOW-TITLE-BAR.md).

Native Linux, Flatpak and Nix feature checks, application tests, production builds,
current advisories and both Nix architecture GUI/installation checks remain
required. The protected signing/publication workflow must independently verify
its exact same-run binaries, signatures, final scans, provenance and public asset
inventory. An owner approval does not replace any preceding verification gate.

The implementation review and current execution results are maintained outside
the source repository; this document states the release requirements and does
not assert that an unexecuted gate passed.
